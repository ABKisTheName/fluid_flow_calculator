# Fluid Flow & Heat Transfer Calculator 🌊⚙️

An interactive engineering computation suite built with Python and Streamlit for hydraulic analysis, friction factor estimations, and fluid flow calculations.

---

## 📌 Features

* Unit Conversions: Automated conversion from standard engineering input units to strict SI units.
* Hydraulic Calculations: Calculates pressure loss in incompressible pipe flow using the Darcy-Weisbach Equation.
* Explicit Friction Factors: Computes friction factor estimations using the Swamee-Jain Equation.
* Interactive UI: Web interface powered by Streamlit for instant inputs and parameter visualization.

---

## 🛠️ Tech Stack

* Language: Python 3.x
* UI Framework: Streamlit
* Libraries: NumPy, Math
